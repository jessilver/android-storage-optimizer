# 🤝 Contribuindo com o Projeto

Sinta-se à vontade para abrir issues ou sugerir melhorias!

## Convenções de Commit
Utilize commits descritivos seguindo o padrão:
* `feat: Adiciona funcionalidade de listagem de pacotes -3`
* `fix: Corrige tratamento de timeout no ADBClient`
* `docs: Atualiza documentação do roadmap`
