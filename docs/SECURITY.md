# Política de Segurança

## Versões Suportadas
Atualmente, apenas a versão mais recente deste projeto recebe atualizações de segurança e correções.

## Reportando uma Vulnerabilidade
Como esta ferramenta interage diretamente com o ADB e comandos de sistema no Android, caso encontre alguma falha relacionada à execução de comandos ou tratamento de exceções, por favor abra uma Issue privada ou entre em contato diretamente com o mantenedor.
